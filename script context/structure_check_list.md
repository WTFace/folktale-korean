# 이야기 골격

> 이야기 흐름을 7단계로 잡습니다. 큰 흐름을 이 골격에 얹으면 됩니다. This example is about good main character. bad(hard) start -> good(easy) ending. for evil character you can do opposit: happy(for the character) start -> sad(not easy) ending

## 2. 줄거리 뼈대 양식

```
[핵심 설정]
- 발단:
- 갈등:
- 결말:

[주제 한 문장]
"____________________"

[반전]
1.
2.
3.

[핵심 소품·증표]
-
```

## 7단계 골격

| 단계 | 하는 일 |
|---|---|
| 1. 발단 | start with "Long ago [region or character]". 주인공과 그것의 처지를 보여준다. |
| 2. 일상과 갈등의 씨앗 | 주인공의 평범한 하루. 앞으로 문제가 될 object/상황을 슬쩍 깐다. |
| 3. 사건 발생 | 일상을 뒤흔드는 결정적 사건. 주인공이 움직일 수밖에 없게 만든다. |
| 4. 시련 | 주인공이 겪는 고생·속임수·오해. 이야기의 가장 긴 몸통. 에피소드 여러 개. |
| 5. 위기 | 모든 게 무너지는 순간. 주인공이 가장 밑바닥에 떨어진다. |
| 6. 반전·해결 | 숨겨진 진실이 드러나고, 악인은 벌받고, 주인공은 보상받는다. |
| 7. 마무리 | 짧은 교훈 한두 문장 + 고정 마무리 멘트. |

---

## 각 단계 감 잡기

**1. 발단** — 주인공이 무엇이 없는지(가난·천한 신분·억울함 등)를 분명히 보여줍니다. 마지막 장면에서 이게 뒤집힐수록 좋습니다.

**2. 일상과 갈등의 씨앗** — 나중에 주인공을 괴롭힐 object(계모·탐관오리·사기꾼 등)을 미리 등장시킵니다.

**3. 사건 발생** — 밖에서 찾아온 사건입니다. 주인공이 더는 예전처럼 살 수 없게 되는 지점.

**4. 시련** — 여기가 가장 깁니다. 서로 다른 장소·상대·상황으로 에피소드를 여러 개 만드세요. 같은 장면 반복은 지루합니다.

**5. 위기** — 주인공이 가진 것을 잃습니다. 사람이든 관계든 희망이든.

**6. 반전** — 진실이 드러나는 클라이맥스. 증거나 증표로 주인공의 정체·결백을 증명하고, 악인이 무너지고, 주인공이 보상받는 흐름으로.

**7. 마무리** — "착하게 살면 복이 온다"는 식의 뻔한 교훈보다, 이 이야기에 딱 맞는 한 문장이 좋습니다. 그리고 고정 마무리 멘트.

## 복선 감 잡기

이야기가 짜임새 있어 보이려면, 앞에서 심은 걸 뒤에서 회수하면 좋습니다.

- 도입에서 보여준 주인공의 결핍 → 반전에서 채워짐
- 초반에 등장한 물건·증표 → 클라이맥스에서 정체 증명에 사용
- 시작 장면과 마지막 장면을 대칭으로 (거지 → 귀인)
