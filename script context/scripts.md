# scripts.md — 대본 점검 안내

매 챕터를 쓴 뒤, 그리고 대본을 합친 뒤에 아래 항목을 점검합니다.

## Check list for each Chapter

- **단어수** — 목표 분량에 맞는지 ( about 154 wpm).
- **따옴표 짝** — 여는 따옴표와 닫는 따옴표 개수가 맞는지.
- **한자** — 한자가 섞이지 않았는지 (no chinese letter).

## 합본 점검

모든 챕터를 이어붙인 뒤 아래를 확인합니다.

- **전체 단어수** — 목표 분량 대략 30 mins / 60 mins.
- **대사 비중** — 대사가 충분히 들어갔는지 (요약 나레이션만 이어지면 지루함).
- **문장 길이** — 지나치게 긴 문장이 많지 않은지 (낭독용은 짧게).

## 처리

- 문제가 있으면 그 부분만 고칩니다.
- 같은 부분을 두 번 이상 고쳐도 안 되면 그대로 두고 넘어갑니다 (limit 2).
